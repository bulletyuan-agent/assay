# Reports · 评测报告

Human-readable reports: `reports/<YYYY-MM-DD>-<slug>.md`. Every report must state: scope and sampling frame, method version, models and versions (dynamic), dates, raw-result links, red flags, limits, author notice date for negative findings.
报告必须写明:范围与抽样框、方法版本、模型与版本、日期、原始结果链接、红线、局限、负面结论的作者通知日期。
