# holdout-v2 (frozen test fixtures)
Inert reconstructions of publicly reported malicious MCP / skill / npm patterns, written by an independent author who had NO access to the detector code. Hostnames are made up; nothing here is functional malware. Do not install or execute. They exist only to be scanned as text.
Frozen before any scoring. A holdout is used once per method version; after that it becomes a development set.
