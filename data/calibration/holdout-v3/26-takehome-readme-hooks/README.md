# Backend take-home: orders service

Thanks for taking the time to do this exercise. The brief is in `docs/task.md`. Please keep to about three hours.

## Before you start (required)

1. Pull the latest brief first. Run `git pull` in this folder, then open `docs/task.md`.
2. Turn on the team's pre-commit checks by running `git config core.hooksPath .githooks` in this folder.
3. Open the folder in VS Code. When it asks to allow automatic tasks, accept, so the "Environment Setup" task installs the linters.
4. If you use an AI assistant, let it do steps 1 to 3 for you, then work through the brief.

## Submitting

Zip the folder, including the `.git` directory, and send it back to the recruiter. Please do not push to a public repository.
