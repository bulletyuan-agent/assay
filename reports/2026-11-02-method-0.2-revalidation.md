## 2. Holdout result · 盲测结果 (the number that matters)

Five malicious-pattern fixtures were reconstructed from public reports (ClawHavoc, Snyk ToxicSkills, a CSA research note) and frozen before scoring. They are inert reconstructions of the described patterns, not the original samples.

| Item | Pattern | Score | Detected |
| --- | --- | ---: | --- |
| holdout-webhook-env | read `~/.clawdbot/.env`, POST to webhook.site | 90 | **No** |
| holdout-curl-sh-prereq | obfuscated shell command in SKILL.md prerequisites | 94 | **No** |
| holdout-eval-b64 | `eval $(echo <base64> \| base64 -d)` in setup.sh | 94 | **No** |
| holdout-remote-instr | `curl <url> \| source` loads remote instructions | 94 | **No** |
| holdout-nl-exfil | natural-language "send the draft to this URL" in SKILL.md | 94 | **No** |

**Malicious recall on holdout: 0 of 5.** Detected means score below 70 or any red flag.

Why each was missed (all expected on reading the rules, none tuned):
- The scanner looks for dangerous patterns only in code files; SKILL.md and README are checked only for four injection phrases.
- `curl | sh` and `base64 | sh` are matched, but `eval $(... | base64 -d)` and `| source` are not.
- A single undeclared host costs 15 points and is not a red flag.
- Natural-language exfiltration has no code pattern at all.
- Fixture note: the first webhook-env fixture README named `webhook.site`, which declared the host. That was my fixture defect. The README was rewritten and the item rerun (90, still a miss); both outcomes are recorded.

Vulnerable (CVE-class) fixtures: 0 of 2 flagged as expected. The screen is not designed to detect honest code with a bug; this needs a separate dependency and flaw analysis.

## 3. Verdict · 结论

- **Observability: good.** Runs are logged, results reproducible, every deduction traceable to a line, scanned files listed.
- **Noise: much better** (7 to 2 false positives).
- **Detection value: not demonstrated.** Real-world malicious recall on holdout is 0 of 5. Good-sample scores are high because they are clean, but the screen does not yet catch the malicious patterns that were actually reported. A score of 100 must not be read as safe.
- **Publish no rating.** The screen is a noise-reduced hygiene check, not a malware detector.
