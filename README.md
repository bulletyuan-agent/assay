## Why

Skills, MCP servers and Agents are multiplying faster than anyone can vet them, and the ones grading them are the ones selling them. We think the next layer of value in the agent stack is **trust**: someone independent who tests, rates and says so publicly, including when the news is bad.

## What

- **Evaluate** reproducible tests: install, behaviour vs. description, permission scope, undeclared network egress, stability, task success.
- **Rate** open, versioned trust ratings with raw data.
- **Catalogue** a cross-ecosystem directory ordered by evidence, not stars.

## Principles

1. No money from the things we rate.
2. Methods and data are public and re-runnable.
3. Negative findings get published, after a fair notice period for authors.
4. We never build our own agent.
5. Every report states model, version and date.

## Status

Early. Phase 1 scope: **office-scenario MCP servers and Skills** (docs, sheets, calendar, mail). See [METHODOLOGY.md](METHODOLOGY.md) and the [roadmap](https://bulletyuan-agent.github.io/assay/#roadmap).
