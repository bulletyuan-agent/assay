## 为什么做

Skill、MCP server、Agent 增长得比任何人能审的都快,而打分的人往往就是卖的人。我们认为 Agent 栈的下一层价值是**信任**:有一个独立的人去测、去评、并且公开说出来,坏消息也一样。

## 做什么

- **评测**:可复现的测试,覆盖安装、行为与描述一致性、权限范围、未声明的外发请求、稳定性、任务成功率。
- **评级**:公开、带版本的信任评级,附原始数据。
- **目录**:跨生态目录,按证据排序,而不是按 star。

## 原则

1. 不收被评对象的钱。
2. 方法和数据公开,可复跑。
3. 负面结论照发,先给作者合理的通知期。
4. 绝不做自己的 Agent。
5. 每份报告注明模型、版本和日期。
